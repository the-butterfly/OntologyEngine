# Case 3: 亚太区总部税务架构优化 — What-If Simulation

## 业务场景

某跨国消费品集团正在评估亚太区总部架构重组方案，需要在三个潜在选项中选择最优税务结构：

- **场景A (香港总部)**: 香港作为区域IP控股中心
- **场景B (新加坡总部)**: 新加坡作为区域运营总部
- **场景C (混合架构)**: 香港持有IP + 新加坡负责运营

## 业务背景

### 集团结构

- **母公司**: 中国消费品集团（A股上市公司）
- **目标市场**: 中国大陆、香港、东南亚（日韩）
- **年收入**: 约80亿人民币
- **员工数量**: 12,000人（分布在中港澳新）

### 核心问题

1. **转让定价合规**: 关联方交易需符合BEPS Action 13要求
2. **支柱二影响**: 2025年起中港澳新均实施QDMTT，有效税率需达15%
3. **税务效率 vs 合规风险**: 需要在税务优化和BEPS风险间取得平衡

## 三个场景方案

### 场景A: 香港总部模式

```
母公司(中国)
    ↓ 100%持股
香港IP控股公司 (SUB_HK)
    ↓ IP授权
新加坡运营公司 (SUB_SG)
    ↓ 制造委托
中国制造子公司 (SUB_CN)
```

**税务特征**:
- 香港: 16.5%利得税，地域征税原则
- 特许权使用费预提税: 5% (中港协定)
- 股息预提税: 5% (中港协定)
- 实质经济要求: 中等

### 场景B: 新加坡总部模式

```
母公司(中国)
    ↓ 100%持股
新加坡运营总部 (SUB_SG)
    ↓ 全权管理
中国制造子公司 (SUB_CN)
```

**税务特征**:
- 新加坡: 17%企业所得税，Pioneer Certificate优惠
- 特许权使用费预提税: 7% (中新协定)
- 股息预提税: 5% (中新协定)
- QDMTT 2025年实施，需补足至15%

### 场景C: 混合架构模式

```
母公司(中国)
    ↓ 100%持股
香港IP控股公司 (SUB_HK)
    ↓ IP授权 + 股权
新加坡运营总部 (SUB_SG)
    ↓ 制造委托
中国制造子公司 (SUB_CN)
```

**税务特征**:
- 香港: IP授权收入，16.5%利得税
- 新加坡: 运营利润，17%企业所得税
- 两地均需满足QDMTT
- 合规复杂度最高

## What-If 模拟目标

通过What-If干运行模拟，对比三个场景的:

1. **有效税率 (ETR)**: 各辖区实际税负
2. **转让定价风险**: BEPS Action 8-10合规评估
3. **税后利润流**: 资金从运营地到控股地的成本
4. **支柱二补税风险**: GloBE规则影响
5. **综合税务效率**: 得分矩阵

## 合规要求

### 转让定价同期资料 (BEPS Action 13)

- **主文档**: 集团层面转让定价政策
- **本地文档**: 各辖区关联交易详情
- **国别报告**: 年收入>7.5亿欧元门槛

###支柱二 (GloBE) 规则

- 最低有效税率: 15%
- 适用门槛: 年合并收入>7.5亿欧元
- 补足税机制: QDMTT
