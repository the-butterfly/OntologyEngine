# 前端 DAG 可视化技术选型分析报告

## 背景

规则编排画布需要满足以下核心需求：
1. **节点编辑能力**：点击节点弹出参数配置面板
2. **DAG 可视化**：展示输入→算子→输出的计算流程
3. **自定义节点样式**：不同算子类型需要差异化的视觉呈现
4. **交互功能**：拖拽、连接、删除、缩放、全屏

## 技术方案对比

### 1. React Flow (@xyflow/react)

**优点**：
- React 原生，状态管理集成良好
- 受控组件架构，nodes/edges 完全可控
- 社区活跃，文档完善
- 轻量级，学习成本低

**缺点**：
- 节点自定义依赖 CSS 类覆盖，定制能力有限
- 没有内置的 snapline（对齐线）功能
- minimap 定制受限
- 与 Ant Design 组件集成需要额外样式处理

### 2. AntV X6

**优点**：
- 基于 SVG，节点定制能力极强（支持 React 组件作为节点）
- 丰富的内置插件：minimap、snapline、selection、clipboard、history 等
- 企业级稳定性，蚂蚁金服生产验证
- 与 Ant Design 5 完美集成
- DAG 布局算法支持（dagre）

**缺点**：
- 学习曲线稍陡
- 状态管理需要手动处理

### 3. AntV G6

**适用场景**：大规模知识图谱展示（只读）

**不适用原因**：
- 编辑能力较弱
- 自定义交互成本高

---

## 选型建议

### 结论：迁移到 X6

**理由**：

| 需求 | React Flow | X6 | 备注 |
|------|-------------|-----|------|
| 节点参数配置面板 | ⚠️ 需额外处理 | ✅ Drawer + 自定义节点 | X6 更灵活 |
| 自定义节点样式 | ⚠️ CSS 覆盖 | ✅ React 组件直渲染 | X6 优势明显 |
| snapline 对齐线 | ❌ 无内置 | ✅ 内置插件 | DAG 编辑必需 |
| minimap | ⚠️ 定制受限 | ✅ 完整控制 | X6 优势 |
| Ant Design 集成 | ⚠️ 样式冲突 | ✅ 无冲突 | X6 优势 |
| 布局算法 | ⚠️ 有限 | ✅ dagre 内置 | DAG 必需 |

### 迁移计划

1. **Phase 1（当前）**：保留 React Flow，完成节点配置面板
2. **Phase 2**：评估是否需要 snapline 等高级功能
3. **如需**：迁移到 X6

### 决策依据

设计文档（`docs/08-visualization-system.md`）明确指出：
> G6 用于 Schema 图（大规模只读）
> X6 用于规则 DAG（自定义节点+交互）

当前 MVP 阶段 React Flow 足够，如需高级编辑功能（snapline、节点分组等），应迁移到 X6。
