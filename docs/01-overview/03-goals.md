# 项目目标

> **status**: proposed | **phase**: mvp+phase1 | **source_of_truth**: 本文档 | **last_verified**: 2026-04-19
> **[关键设计点]**: 本文档定义 OntologyEngine 的阶段性目标，是项目阶段判断的唯一入口

---

## 核心目标

OntologyEngine 解决一个根本矛盾：**企业知识以三种形态存在（IT 资产、个人资产、组织资产），但彼此断裂，无法形成可追溯的决策链。**

OntologyEngine 的解法：**三层资产链接 + Layer-R/S 双层认知架构 + 作业即沉淀闭环。**

---

## 做与不做

### 我们做什么

| 能力 | 验收标准 | 来源 |
|------|---------|------|
| **Schema 驱动的三层资产统一描述** | KGML YAML 声明 IT/个人/组织三类资产 | KAG SPG Schema |
| **L1-L4 四层推理链路** | 事实→归类→分析→决策，完整可追溯 | m_flow Cone Graph |
| **Layer-R 原文优先检索** | 向量检索 + 互索引 + 矛盾检测（ingest时） | MemPalace + LLM-Wiki |
| **Layer-S 结构化推理** | 图遍历 + Bundle Search + 传递推理 | m_flow + MAMGA |
| **规则热更新** | YAML 修改后秒级生效 | KAG Expert Rules DSL |
| **个人→组织知识沉淀** | 使用次数+置信度 → 候选标记 → 专家评审 → 发布 | LLM-Wiki |
| **增量提取 + SHA256 缓存** | 只重处理变化文件 | Graphify |

### 我们不做什么

| 非目标 | 原因 |
|--------|------|
| **通用 NLP 平台** | 专注结构化知识推理，不做通用文本理解 |
| **替代数据仓库** | 不做 OLAP，专注实时规则推理 |
| **通用文档检索** | RAG 广度层由外部系统提供，OntologyEngine 专注深度推理层 |
| **Agent 会话记忆** | Memory 连续性层由外部 Agent 框架提供，OntologyEngine 提供知识接口 |
| **拖拽式规则设计器** | Phase 2 前无可视化编排 |
| **多租户 SaaS** | Phase 3 前不考虑租户隔离 |
| **通用图计算引擎** | 专注业务规则推理，不做通用图分析 |

## 阶段目标

### Phase 0: MVP（当前）

**Deadline**: 2026-04-30

| 目标 | 验收标准 |
|------|----------|
| **Schema 可定义** | KGML YAML 解析通过，支持 IT/个人/组织资产声明 |
| **规则可执行** | 供应链金融 5 条规则跑通 |
| **Demo 可演示** | 单脚本运行完整 L1-L4 推理链路 |

### Phase 1: 奠基（4周）

**Deadline**: 2026-05-31

| 目标 | 验收标准 |
|------|----------|
| **本地图存储** | KuzuDB 接入，图遍历/路径查询/担保圈检测可用 |
| **Layer-R 检索** | ChromaDB 向量检索 + Dataset/Fragment 管理 |
| **互索引基础** | extracted_from / trace_to 双向链接可运行 |
| **MCP 协议支持** | Claude Agent 可调用 OntologyEngine 工具 |
| **规则热更新** | YAML 修改秒级生效 |
| **时序查询** | 时序实体支持 as_of 查询，默认返回当前版本 |

### Phase 2: 协同（4周）

**Deadline**: 2026-06-30

| 目标 | 验收标准 |
|------|----------|
| **Layer-R/S 协同检索** | Layer-R 检索 → Layer-S 推理 → trace_to 回溯，完整链路 |
| **矛盾检测** | Ingest 时检测，异步扫描可用 |
| **Bundle Search** | 边向量参与评分，最小成本路径检索 |
| **个人→组织沉淀** | 使用次数+置信度自动标记，评审后发布 |
| **多场景** | 3 个垂直领域 Schema（BI 问数/风险识别/税务意见） |
| **可视化** | Schema 图/规则链/执行结果 Web UI |

### Phase 3: 规模（4周）

**Deadline**: 2026-07-31

| 目标 | 验收标准 |
|------|----------|
| **50W 节点支撑** | Kuzu 优化，内存图索引 |
| **反馈闭环** | 反馈 → 影响分析 → 人工确认 → 自动执行 |
| **企业级** | RBAC、审计、SLA |
| **知识治理** | 新鲜度评分、血缘追踪、语义标签、所有权元数据 |
