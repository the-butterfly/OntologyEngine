# OntologyEngine 愿景

## 一句话定义

面向 AI Agent 的下一代知识库系统 —— 让机器像专家一样理解业务语义。

## 核心命题

传统知识库回答"是什么"，OntologyEngine 回答"意味着什么"。

```
传统: 公司A注册资本1000万 → 存储
OntologyEngine: 公司A注册资本1000万 + 行业均值500万 → 资本充足度评级"高"
```

## 三层跃迁

| 层级 | 能力 | 示例 |
|------|------|------|
| L1 事实层 | 存储实体关系 | 供应商X向Y供货 |
| L2 分析层 | 计算指标评分 | 供应商信用分85 |
| L3 决策层 | 生成业务建议 | 建议授信额度500万 |

## 技术哲学

1. **Schema 即代码** —— 业务知识用声明式 YAML 定义，非硬编码
2. **本地优先** —— 单机可运行百万级节点，零外部依赖
3. **AI Native** —— 为 Agent 设计 Memory 接口，非事后兼容
