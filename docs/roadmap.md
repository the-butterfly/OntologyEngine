# 开发路线图

## Phase 1: 基础骨架 (4周)

**目标**: 可运行的基础系统

| 周 | 任务 | 产出 |
|----|------|------|
| W1 | 项目搭建、Schema 定义 | 项目结构、Pydantic 模型 |
| W2 | Neo4j 集成、基础 CRUD | 图存储接口 |
| W3 | FastAPI 服务、基础查询 | REST API |
| W4 | 数据导入、单元测试 | ETL、测试覆盖 |

**Milestone**: 可导入 KGML，基础查询可用

## Phase 2: 规则引擎 (4周)

**目标**: 声明式规则执行

| 周 | 任务 | 产出 |
|----|------|------|
| W1 | 规则模型、算子设计 | Operator 基类 |
| W2 | 依赖解析 (DAG) | networkx 集成 |
| W3 | 规则执行器 | 完整规则链执行 |
| W4 | 指标计算 | MetricEngine |

**Milestone**: 可配置规则，自动计算指标

## Phase 3: 向量与检索 (3周)

**目标**: 语义检索能力

| 周 | 任务 | 产出 |
|----|------|------|
| W1 | pgvector 集成 | 向量存储 |
| W2 | Embedding 生成 | 文本向量化 |
| W3 | 混合检索 | 图+向量联合查询 |

**Milestone**: 语义搜索可用

## Phase 4: Agent 集成 (3周)

**目标**: Agent 可用

| 周 | 任务 | 产出 |
|----|------|------|
| W1 | Memory 模型 | 上下文存储 |
| W2 | Memory 检索 | 关联检索 |
| W3 | gRPC/MCP 协议 | Agent 接口 |

**Milestone**: Agent 可查询知识库

## Phase 5: 反馈闭环 (2周)

**目标**: 用户反馈回流

| 周 | 任务 | 产出 |
|----|------|------|
| W1 | 反馈收集 | Feedback API |
| W2 | 知识更新 | 自动更新流程 |

**Milestone**: 反馈驱动知识进化

## 总计: 16周 (4个月)
