### Phase 1: 实现 `_filter_steps()` 从 L4 层提取规则步骤 [P0]

#### 任务 1.1: 定义 ExecutableStep 数据结构

**文件**: `ontology_engine/engine/rule/models.py`

需要扩展现有模型:

```python
class ExecutableStep(BaseModel):
    step_id: str
    step_name: str
    rule_group_name: str
    rule_group_type: Literal["constraint", "inference", "alert", "decision"]
    condition: Condition
    action: Action
    output_names: list[str]
    depends_on: list[str]
    priority: int
    entity_filter: str | None = None
```

#### 任务 1.2: 实现 `_filter_steps()` 方法

**文件**: `ontology_engine/services/simulation_tree_builder.py`

**实现逻辑**:
1. 接收 `RuleGroupDefinition[]` (来自 L4 层)
2. 对每个 rule_group，提取 rule_logics 中的步骤
3. 解析 `when.expression` 构建 condition
4. 解析 `then_action` 构建 action
5. 提取 inputs/outputs 名称
6. 根据 `entity_id` 过滤 `applies_to.categories`
7. 返回 `ExecutableStep[]`

**伪代码**:
```python
async def _filter_steps(
    self,
    groups: list[RuleGroupDefinition],
    entity_id: str | None,
) -> list[dict[str, Any]]:
    steps = []
    for group in groups:
        logics = await self._get_rule_logics(group.definition_id)
        for logic in logics:
            condition = parse_expression(logic.when.expression)
            action = parse_action(logic.then_action)
            step = {
                "step_id": f"{group.id}.{logic.id}",
                "step_name": logic.name,
                "rule_group_name": group.name,
                "rule_group_type": group.rule_type,
                "condition": condition,
                "action": action,
                "output_names": [o.id for o in group.outputs],
                "depends_on": [],
                "priority": group.priority,
            }
            steps.append(step)
    return steps
```

#### 任务 2.1: 扩展 RuleTreeBuilder 依赖

**文件**: `ontology_engine/services/simulation_tree_builder.py`

**修改**:
1. 注入 `SemanticSpaceStorage` 或 `ManagementAPI`
2. `_locate_by_output()` 直接从 SemanticSpace L4 层查询

**伪代码**:
```python
async def _locate_by_output(
    self,
    output_name: str,
    schema_id: str,
) -> list[RuleGroupDefinition]:
    space = await self._semantic_space_storage.get(schema_id)
    results = []
    for rule_def in space.layers.L4_business_logic.rule_definitions:
        for output in rule_def.outputs:
            if output.id == output_name:
                results.append(rule_def)
                break
    return results
```

**决策**: Schema 使用一致的标准化属性，加载时检查字段一致性

**检查点**:

| 检查点 | 检查内容 | 失败处理 |
|--------|----------|----------|
| Schema 加载 | 嵌套属性路径如 `registered_capital.value` 是否存在 | 报错 + 拒绝加载 |
| 规则加载 | 规则引用的 `inputs/outputs` 在 schema 中是否存在 | 报错 + 拒绝加载 |
| 实例加载 | 实例属性与 schema 定义的类型是否匹配 | 警告 + 类型转换 |
